# dolin.digital

The ultimate personal meme site.

## Features

- Full-volume Never Gonna Give You Up on entry
- Mute button that doesn't mute (and actively unmutes)
- Close / X button that runs away from your mouse
- ESC key spawns more runaway buttons
- Attempts to keep the video playing and volume maxed
- Fullscreen request
- Right-click disabled for extra fun

## Deploy

1. Push to GitHub (already done if you're reading this)
2. Go to Settings → Pages
3. Source: Deploy from a branch
4. Branch: main / root
5. Save

Then visit `https://wdolin1.github.io/dolin-digital/`

Or point your custom domain dolin.digital at the GitHub Pages URL.

## Local preview

Open `index.html` in a browser. Click ENTER.

## Notes

Autoplay with sound requires a user gesture in modern browsers — hence the big ENTER button. Once clicked, it locks you in as best as possible.

Have fun. Never gonna give you up.
